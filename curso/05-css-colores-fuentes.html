5. CSS: colores, fuentes y cajas

CSS aplica reglas visuales a los elementos HTML. Una regla contiene un selector y una o más declaraciones.

Cómo se escribe una regla

p {
  color: navy;
  font-size: 18px;
}

p es el selector. color y font-size son propiedades; los valores aparecen después de los dos puntos. Cada declaración termina con punto y coma.

El elemento link conecta el HTML con una hoja CSS externa:

<link rel="stylesheet" href="estilos.css">

Seleccionar elementos y clases

/* Selecciona todos los párrafos */
p {
  color: #333333;
}

/* Selecciona los elementos con class="aviso" */
.aviso {
  background-color: lightyellow;
  padding: 12px;
}

Este párrafo tiene la clase aviso.

En HTML, class="aviso" se escribe sin punto. En CSS, el selector de clase se escribe con punto: .aviso. Una misma clase puede usarse en varios elementos.

Colores y tipografía

Texto azul sobre un fondo suave.

Una fuente distinta, más grande y en negrita.

.muestra-color {
  color: #174a7e;
  background-color: #e8f1fa;
}

.muestra-fuente {
  font-family: Georgia, serif;
  font-size: 1.25rem;
  font-weight: bold;
  text-align: center;
}

Los colores se pueden indicar con nombres, códigos hexadecimales como #174a7e o funciones como rgb(23, 74, 126). Para fuentes, una lista de alternativas ayuda si la primera no está instalada.

font-size cambia el tamaño; font-weight cambia el grosor; text-align alinea el texto.

Espacio, borde y caja

Contenido dentro de una caja con espacio interior, borde y separación exterior.
.caja {
  padding: 16px;       /* espacio dentro del borde */
  border: 2px solid #174a7e;
  margin: 16px 0;      /* espacio fuera del borde */
  border-radius: 6px;
}

padding separa el contenido del borde. border dibuja el borde. margin separa esta caja de otros elementos. border-radius redondea las esquinas.
