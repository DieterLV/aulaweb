6. CSS: display, columnas e imágenes

La propiedad display cambia cómo se colocan los elementos. Flexbox y Grid son herramientas nativas de CSS para organizar contenido en filas y columnas.

Block, inline e inline-block

Elemento block: empieza en una línea nueva. Inline 1 Inline 2 Inline-block con ancho 
.block { display: block; }
.inline { display: inline; }
.inline-block { display: inline-block; width: 180px; }

block normalmente ocupa el ancho disponible y empieza en otra línea. inline comparte la línea con el texto. inline-block se coloca en línea, pero permite definir ancho y alto.

Flexbox: organizar elementos en una fila

.fila {
  display: flex;
  gap: 12px;
  flex-wrap: wrap;
}

Flexbox resulta útil para alinear elementos en una dirección, como enlaces de navegación, botones o una fila de tarjetas. gap deja espacio entre elementos y flex-wrap permite que bajen a otra línea si falta espacio.

Centrar una caja

Para centrar horizontalmente una caja con un ancho definido, puedes usar margin-inline: auto. El elemento conserva su propio ancho y los márgenes izquierdo y derecho se reparten por igual.

Esta caja está centrada.
.caja-centrada {
  width: min(100%, 320px);
  margin-inline: auto;
}

Para centrar los elementos que están dentro de un contenedor, usa Flexbox: display: flex; justify-content: center; align-items: center;. La primera propiedad centra en el eje principal (horizontal por defecto); la segunda en el eje transversal.

Contenido centrado con Flexbox 
.contenedor {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 120px;
}

Estos métodos no hacen lo mismo: margin-inline: auto centra una caja en su espacio disponible; Flexbox alinea los elementos hijos dentro de un contenedor.

Grid: crear columnas

Otra fila 2
.columnas {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  gap: 12px;
}

@media (max-width: 600px) {
  .columnas {
    grid-template-columns: 1fr;
  }
}

grid-template-columns define las columnas. 1fr significa una parte del espacio disponible. La regla @media cambia el diseño en pantallas pequeñas; así las dos columnas pasan a una.

Imágenes con HTML y CSS

img {
  max-width: 100%;
  height: auto;
}

Usa img cuando la imagen comunica algo y añade un alt adecuado. Para una imagen decorativa que forma parte del diseño, CSS puede usar background-image; no reemplaza el texto alternativo de una imagen informativa.

.fondo {
  background-image: url("imagenes/paisaje.svg");
  background-size: cover;
  background-position: center;
}

La ruta de url() se calcula desde el archivo CSS, no desde el HTML.
