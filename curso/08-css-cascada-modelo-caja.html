8. CSS: cascada y modelo de caja

Cuando un estilo no aparece como esperabas, revisa qué reglas coinciden, cuál tiene mayor especificidad y cuánto mide la caja.

La cascada decide qué regla gana

Si varias reglas asignan la misma propiedad al mismo elemento, CSS compara su importancia y especificidad; cuando empatan, normalmente gana la que aparece después. Evita resolver todos los conflictos añadiendo !important: busca primero qué selector está causando la competencia.

p { color: #333; }          /* selector de elemento */
.aviso { color: darkgreen; } /* selector de clase */
#principal { color: navy; }  /* selector de id */

Un selector de id suele tener más especificidad que uno de clase, y uno de clase más que uno de elemento. Escribe selectores sencillos y reutilizables para que sea fácil saber por qué se aplica un estilo.

Este texto coincide con el selector de id y el de clase.

#aviso-cascada { color: firebrick; }
.aviso-cascada { color: darkgreen; }

Prueba el ejemplo en la práctica CSS: cambia o quita una regla y observa cuál deja de ganar.

Las partes de una caja

Una caja se compone de contenido, padding (espacio interior), border (borde) y margin (espacio exterior). Con content-box, el ancho declarado corresponde solo al contenido y el padding y el borde se suman.

.caja {
  width: 320px;
  padding: 24px;
  border: 4px solid navy;
  box-sizing: border-box;
}

box-sizing: border-box hace que el ancho declarado incluya el contenido, el padding y el borde. Aplicarlo de forma consistente ayuda a evitar desbordamientos:

* {
  box-sizing: border-box;
}
El ancho exterior no supera el contenedor.

Prueba a cambiar el padding y el borde en el editor.

Un método para investigar estilos

  1. Comprueba que el selector coincide con el elemento.
  2. Busca otra regla que declare la misma propiedad.
  3. Compara especificidad y orden de las reglas.
  4. Revisa el modelo de caja si el tamaño o el espacio no coincide.
