10. HTML: formularios y multimedia

HTML puede comprobar algunos datos antes de enviar un formulario y mostrar audio o video con controles del navegador. La validación no reemplaza la comprobación que debe realizar un servidor.

Validación nativa del navegador

Combina el tipo de campo con atributos que describen lo que se espera. El navegador reconoce correos con type="email", campos obligatorios con required y límites numéricos con min y max.

Inscripción al taller 
<label for="edad">Edad</label>
<input id="edad" name="edad"
       type="number" min="12" max="99" required>

Agrupa opciones relacionadas con fieldset y nómbralas con legend. Cada control debe tener una etiqueta asociada mediante for e id.

Para opciones, crea un select con una primera opción vacía y requerida; el navegador puede impedir el envío hasta que se elija una alternativa.

Audio y video con alternativas

controls muestra controles de reproducción. Añade un nombre accesible y una alternativa escrita cuando el medio sea importante; para video con diálogo o información sonora, proporciona subtítulos con track.

<video controls aria-label="Video: cómo plantar una semilla">
  <source src="plantar-semilla.mp4" type="video/mp4">
  <track kind="captions" src="subtitulos-es.vtt"
         srclang="es" label="Español">
  Tu navegador no puede reproducir este video.
</video>

Los archivos de audio, video y subtítulos deben existir en las rutas indicadas. El texto alternativo entre las etiquetas ayuda si el navegador no puede reproducir el archivo.

Información útil en el encabezado del documento

El title da un nombre a la página y la descripción ayuda a resumir su contenido. El atributo lang en html indica el idioma del documento; viewport permite presentar correctamente el diseño en dispositivos estrechos.

<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport"
        content="width=device-width, initial-scale=1">
  <meta name="description"
        content="Descripción breve de la página.">
  <title>Mi proyecto</title>
</head>
