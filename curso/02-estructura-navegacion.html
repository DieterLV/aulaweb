2. Secciones y navegación

Las etiquetas semánticas describen la función del contenido. Ayudan a que el documento sea más fácil de entender para personas, navegadores y tecnologías de asistencia.

Partes comunes de una página

  • header: encabezado de la página o de una sección.
  • nav: conjunto de enlaces para desplazarse o navegar.
  • main: contenido principal; normalmente hay uno por página.
  • section: grupo temático que suele tener un título.
  • article: contenido independiente, como una noticia o receta.
  • footer: información final, como autoría o contacto.
<header>
  <h1>Mi sitio</h1>
  <nav aria-label="Principal">
    <a href="#noticias">Noticias</a>
  </nav>
</header>
<main>
  <section id="noticias">
    <h2>Noticias</h2>
    <article>
      <h3>Título de una noticia</h3>
      <p>Contenido de la noticia.</p>
    </article>
  </section>
</main>
<footer>Fin de la página</footer>

¿Cuándo usar div?

div es un contenedor genérico: agrupa elementos cuando no hay una etiqueta semántica más adecuada. No significa “caja con diseño”; el diseño se aplica después con CSS.

<div class="grupo-de-botones">
  <a href="registro.html">Registrarme</a>
  <a href="ayuda.html">Ayuda</a>
</div>

Si el contenido tiene un tema propio, prefiere section. Si podría entenderse por separado, considera article. Si solo necesitas agrupar elementos para aplicarles una clase, div puede ser apropiado.

Enlaces dentro de la misma página

El valor de href comienza con # y debe coincidir con el id del destino.

Ir al tema final de esta lección

<a href="#tema-final">Ir al tema final</a>
...
<section id="tema-final">
  <h2>Tema final</h2>
</section>

Tema final

Al hacer clic en el enlace anterior, el navegador busca el elemento que tiene id="tema-final".
