9. CSS: diseño adaptable y estados

Un diseño adaptable reorganiza el contenido según el espacio disponible. Los estados de interacción deben ser claros tanto con el ratón como con el teclado.

Empieza por un diseño flexible

Usa anchos máximos, medidas relativas y cuadrículas flexibles para que el contenido pueda ajustarse. minmax() limita el tamaño de las columnas; auto-fit permite crear tantas columnas como quepan.

.tarjetas {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(220px, 1fr));
  gap: 1rem;
}

Una consulta de medios aplica reglas cuando se cumple una condición, como un ancho máximo. El punto de cambio debe responder al contenido, no a un modelo específico de teléfono.

@media (max-width: 640px) {
  .menu {
    flex-direction: column;
  }
}

Estados para ratón y teclado

:hover indica que el puntero está sobre un elemento. :focus-visible muestra el foco cuando una persona navega con el teclado. No quites el contorno sin ofrecer una señal visible equivalente.

.menu a:hover,
.menu a:focus-visible {
  color: #20243a;
  background-color: #f0c65e;
  outline: 3px solid #e85d3f;
  outline-offset: 2px;
}

Prueba estos enlaces con el ratón y con la tecla Tab. Ambos modos deben permitir identificar qué elemento está activo.

Comprueba diferentes anchos

  1. Empieza con el contenido y las columnas.
  2. Reduce el ancho de la vista previa poco a poco.
  3. Busca desbordamientos y decide cuándo reorganizar los elementos.
  4. Usa la consulta de medios más pequeña que mantenga el contenido legible.

En la práctica CSS, elige “Diseño adaptable y foco” para modificar el menú y las tarjetas.
