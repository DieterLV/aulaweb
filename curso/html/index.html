CURSO 01 · FUNDAMENTOS Y ACCESIBILIDAD

Aprende HTML

HTML es el lenguaje que organiza y describe el contenido de una página. En este curso nos enfocamos en qué significa cada etiqueta y cuándo usarla. Los estilos visuales se estudian en el curso de CSS.

No necesitas saber CSS para empezar. Las páginas tienen una presentación sencilla para que puedas concentrarte en el contenido.
