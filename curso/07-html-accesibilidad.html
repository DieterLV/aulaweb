7. HTML: semántica y accesibilidad

HTML semántico explica el propósito de cada parte de una página. Una estructura clara ayuda a estudiantes, navegadores y tecnologías de asistencia a entender el contenido.

Elige la etiqueta por su significado

Usa header para la introducción de una página o sección; nav para un grupo de enlaces de navegación; main para el contenido principal; section para un tema con encabezado; article para contenido que tiene sentido por sí solo; y footer para información final.

<header>
  <h1>Club de lectura</h1>
  <nav aria-label="Principal">
    <a href="#libro">Libro del mes</a>
  </nav>
</header>
<main>
  <section id="libro">
    <h2>Libro del mes</h2>
    <article>
      <h3>Una historia para conversar</h3>
      <p>Nos reunimos cada jueves.</p>
    </article>
  </section>
</main>

No elijas una etiqueta solo por su apariencia. Por ejemplo, section agrupa un tema; div es un contenedor neutro cuando no hay una etiqueta semántica adecuada.

Imágenes que comunican

En una imagen informativa, alt debe describir la información importante, no comenzar con “imagen de”. Si una imagen es puramente decorativa y no aporta información, usa alt="".

<figure>
  <img src="paisaje.svg" alt="Montañas verdes junto a un lago">
  <figcaption>Un paisaje de la región.</figcaption>
</figure>

Formularios comprensibles

Un label asociado permite identificar cada campo. El valor de for debe coincidir con el id del control. El atributo required comunica que el campo es obligatorio.

<label for="correo">Correo electrónico</label>
<input id="correo" name="correo" type="email" required>

El texto visible de la etiqueta ayuda a todas las personas. No dependas solamente de placeholder para explicar un campo.

Revisa el orden de los encabezados

Organiza los títulos según la jerarquía del contenido: un título principal con h1, subtítulos con h2 y apartados internos con h3. No saltes niveles solo para cambiar el tamaño visual.

Comprueba además que los enlaces describan su destino y que cada enlace interno apunte a un id existente.
