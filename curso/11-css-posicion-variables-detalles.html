11. CSS: posición, desbordamiento y valores fluidos

Estas herramientas permiten colocar elementos por capas, controlar contenido largo y crear diseños que se ajusten con suavidad al espacio disponible.

Posiciona elementos y organiza capas

position: relative conserva el lugar del elemento y establece una referencia. Un hijo con position: absolute se coloca respecto a esa referencia usando propiedades como top y right.

.tarjeta {
  position: relative;
}

.etiqueta {
  position: absolute;
  top: 12px;
  right: 12px;
  z-index: 1;
}

z-index controla qué elemento se dibuja por encima dentro de su contexto de apilamiento. Úsalo con cuidado: números cada vez mayores no arreglan un contexto mal entendido.

Controla contenido que no cabe

Las propiedades overflow, overflow-x y overflow-y deciden qué hacer cuando el contenido supera el espacio de una caja. auto muestra desplazamiento cuando hace falta; hidden puede ocultar contenido importante, así que úsalo con intención.

Un panel puede contener comentarios, instrucciones o detalles largos. El contenido debe seguir disponible sin invadir el resto de la página.

Cuando el espacio es limitado, un área desplazable permite leer el texto completo manteniendo el tamaño del panel bajo control.

.comentarios {
  max-height: 180px;
  overflow-y: auto;
  padding: 1rem;
}

Añade detalles con pseudoelementos

::before y ::after crean detalles de presentación desde CSS. La propiedad content genera el contenido decorativo; no reemplaza información esencial ni etiquetas HTML.

.enlace-ayuda::after {
  content: " →";
}

.enlace-ayuda:focus-visible {
  outline: 3px solid #e85d3f;
}

Para mostrar información necesaria, es preferible incluirla en el HTML y darle un estado visual claro para :hover y :focus-visible.

Variables y tamaños fluidos

Las propiedades personalizadas se declaran con --nombre y se leen con var(). clamp(mínimo, preferido, máximo) permite que un tamaño crezca o se reduzca sin rebasar límites.

:root {
  --color-acento: #3448c5;
  --espacio: 1rem;
}

h1 {
  color: var(--color-acento);
  font-size: clamp(2rem, 6vw, 4rem);
}

Usa medidas fluidas en conjunto con límites y comprueba el resultado en distintas anchuras, no solo en una captura.
