PRUÉBALO TÚ

Una guía para empezar

No tienes que memorizar todo. Cambia una cosa cada vez y observa el resultado.

  1. 1

    Elige una base

    Usa el menú de ejemplos para cargar una tarjeta, un artículo o una cuadrícula.

  2. 2

    Cambia el contenido

    En la pestaña HTML, cambia el título o el texto. Busca las etiquetas <h1> y <p>.

  3. 3

    Personaliza el estilo

    En CSS, cambia color, background-color, font-size o padding.
