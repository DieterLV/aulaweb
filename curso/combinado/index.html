CURSO 03 · HTML + CSS

Ahora, construye una página completa

Ya conoces la estructura con HTML y la presentación con CSS. En esta ruta aprenderás cómo trabajan juntos y practicarás cada cambio en un editor interactivo.

Recomendado después de los cursos introductorios de HTML y CSS. No necesitas instalar nada.

La idea clave: contenido y presentación

HTML describe qué es cada parte. CSS selecciona esas partes y define cómo se ven. Una clase conecta ambos lenguajes: se escribe en el atributo class del HTML y se selecciona con un punto en CSS.

HTML · qué contiene

<article class="tarjeta">
  <h2>Mi proyecto</h2>
  <p>Estoy aprendiendo.</p>
</article>

CSS · cómo se presenta

.tarjeta {
  padding: 1rem;
  background-color: #e2f4ee;
  border-radius: 8px;
}

El navegador lee el HTML, encuentra el elemento class="tarjeta" y le aplica las reglas que coinciden con .tarjeta.

Ruta de práctica

  1. 1

    Elige una base. Empieza con una tarjeta, un artículo o una cuadrícula.

  2. 2

    Modifica el HTML. Cambia el título, agrega párrafos o crea una sección.

  3. 3

    Modifica el CSS. Cambia colores, bordes, espacios o columnas.

  4. 4

    Compara el resultado. La vista previa muestra los cambios y puedes volver a cargar el ejemplo cuando quieras.
