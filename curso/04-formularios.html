4. Formularios

Los formularios permiten pedir información. HTML crea los campos y sus etiquetas; CSS puede cambiar su apariencia.

Ejemplo para probar

Este formulario es una demostración local: no guarda ni envía datos a un servidor. No ingreses información privada.

Partes del formulario

<form action="/contacto" method="post">
  <label for="correo">Correo</label>
  <input id="correo" name="correo" type="email" required>

  <label for="mensaje">Mensaje</label>
  <textarea id="mensaje" name="mensaje"></textarea>

  <button type="submit">Enviar</button>
</form>
  • form agrupa los campos. action indica dónde se procesarían; method indica cómo se envían.
  • label nombra un campo. Su for debe coincidir con el id del control.
  • name identifica el dato que se enviaría al servidor.
  • required pide al navegador que compruebe que el campo no esté vacío.

Tipos de campos

  • type="text": texto corto.
  • type="email": dirección de correo.
  • type="number": número.
  • type="date": fecha.
  • type="checkbox": opción que se puede activar o desactivar.
  • type="radio": una opción entre varias que comparten el mismo name.
  • select y option: menú de opciones.
  • textarea: texto de varias líneas.

Un formulario real necesita un servidor o servicio que reciba y procese los datos. HTML por sí solo no los guarda.
