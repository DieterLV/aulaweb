CURSO 02 · FUNDAMENTOS, DISEÑO Y DETALLES AVANZADOS

Aprende CSS

CSS describe cómo se presentan los elementos: sus colores, fuentes, bordes, espacios y posición. En estos ejemplos, el HTML necesario ya está preparado; nos concentramos en escribir las reglas CSS.

Conviene conocer primero las etiquetas HTML. No tienes que crear el contenido de las demostraciones: practica modificando el CSS y observa cómo cambia.
